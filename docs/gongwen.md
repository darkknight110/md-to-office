# 公文模板引擎（L2：模板固化）

> **它不是"生成公文"，是"按你的模板填内容"。**
> 版心、字号、行距、页码、红头、版记、印章位都是**你的模板**带的；工具只做三件事：
> 读出来、记住、填进去，最后**量一遍证明没跑偏**。

入口：[`scripts/gongwen.py`](../scripts/gongwen.py)。与 `md2office.py` 分开：
后者是"Markdown → 标准商务文档"，前者是"模板 → 同构文档"，两者契约不同。

---

## 一、为什么不是"参数化公文 profile"

公文真正的差异不在参数，在**版面构件**：红头放哪、版记怎么排、发文字号怎么编、印章压不压日期。
这些每家单位都不一样，参数化永远追不上；而**模板天然就是那份细则**。

所以这里选择：**继承模板**，而不是**猜测规范**。

---

## 二、三条命令

```bash
# 1. 存模板（同时体检：版心/边距/字号/行距/占位符/字体依赖）
python3 scripts/gongwen.py template add 某单位模板.docx --name 某单位

# 2. 看模板记住了什么
python3 scripts/gongwen.py template show 某单位

# 3. 填内容生成（数据来自 JSON + 正文文件）
python3 scripts/gongwen.py render --template 某单位 \
  --data data.json --body 正文.md --out 成文.docx

# 4. 事后校验：产物是否还符合模板
python3 scripts/gongwen.py check 成文.docx --template 某单位
```

`data.json` 的键就是模板里的占位符：

```json
{
  "标题": "关于开展……的通知",
  "主送机关": "各处室：",
  "正文": "（也可用 --body 指定一个 Markdown 纯文本文件）",
  "附件说明": "附件：测试记录表",
  "成文日期": "2026年10月21日",
  "版记": "抄送：办公室。　印发机关：××处　2026年10月21日印发"
}
```

没有模板可试？现场造一份空白公文（无红头、无单位信息）：

```bash
python3 examples/gongwen/make_blank_template.py --out /tmp/空白公文.docx
python3 scripts/gongwen.py template add /tmp/空白公文.docx --name 空白公文
```

## 三、模板必须满足三条

1. **用 Word 样式排版**（正文、标题各自成样式）。
   手工选字号加粗的模板，样式继承拿到的是空壳——`template show` 里字号会是 `None`。
2. **固定要素放在该在的位置**：红头放首页页眉、版记放文末，别混在正文段落里。
   它们在哪儿，产物就在哪儿；工具不会移动它们。
3. **可变处写占位符**：`{{标题}}`、`{{正文}}`……。
   印章位置写成 `{{印章位}}` 或一行说明文字——**工具不会生成印章**。

## 四、存储什么

```
$GONGWEN_HOME/某单位/            # 默认 ~/.md-to-office/templates
├── template.docx                # 原始模板副本（只读）
└── meta.json                    # sha256 / 来源 / 版心边距 / 样式 / 占位符 / 字体依赖
```

- 每次 `render` 前校验 **sha256**：模板被换过会拒绝，除非 `--allow-drift`；
- 字体依赖本机确认不了时显示 `？`，**不假装知道**（macOS 默认没有仿宋，Word 会静默替换成宋体）。

---

## 五、生成后自动比对什么

`render` 结束时会自动跑一遍 `compare()`，与 `check` 同一套判据：

| 项 | 容差 |
|---|---|
| 页面尺寸 | 完全一致 |
| 上/下/左/右页边距 | ±0.6mm |
| Normal / Heading 1 / Heading 2 字号 | ±0.2pt |
| Normal / Heading 1 / Heading 2 行距 | ±0.5pt |
| 首行缩进 | ±0.6mm |

不一致 → 打印差异并以退出码 1 结束（`render` 也会返回 1）。**它不会在跑偏的情况下说"成功"。**

---

## 六、边界（先看这一节）

1. **不生成红头、发文字号、成文日期、印章、版记**——文里出现什么，取决于你的模板里有什么。
2. **印章只保位置，不生成图**：用印是组织行为，不是排版动作。
3. **占位符按 `{{名}}` 文本匹配**：若一个占位符被 Word 拆成多个 run，替换后该段会重写为整段（段内多样式会丢）。
4. **正文按行拆段、丢空行**：公文用首行缩进分段，空行会让版式散掉。
5. **字体是否真的存在，取决于打开文档的那台机器**：工具只能报告"本机能否确认"，不能保证对方装了。
6. **模板错了，产物就错**。它保证"与模板同构"，不保证"模板本身合规"。
