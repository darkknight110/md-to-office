# 示例文档：一个演示用的技术方案

这是一份用于冒烟测试的最小样例，不包含任何真实项目信息。它覆盖转换器需要处理的四类内容：
标题层级、中文段落、表格、代码块，以及一段**ASCII 字符画**。

## 一、目标

把一个 Markdown 文件转换成排版规范的 Word 文档，并验证：

| 项 | 期望 |
|---|---|
| 标题 | 保留层级，字号递减 |
| 表格 | 表头加底色，边框完整 |
| 代码块 | 等宽字体，不折行 |
| 字符画 | 未提供 spec 时**原样保留**（不静默删除） |
